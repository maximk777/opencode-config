# Task 1.3: Greet world for empty name

## Requirement
Empty name greets world: Hello SHALL greet the world when the trimmed name is empty. Scenarios: Hello("") returns "hello world"; Hello("   ") returns "hello world".

## Do
1. Add to greet_test.go:
```go
func TestHelloEmpty(t *testing.T) {
	if got := Hello(""); got != "hello world" {
		t.Fatalf("got %q", got)
	}
}
```
2. Paste this skeleton into greet.go exactly as written, replacing the body of Hello:
```go
func Hello(name string) string {
	if name == "" {
		return "hello world"
	}
	return "hello " + strings.TrimSpace(name)
}
```
