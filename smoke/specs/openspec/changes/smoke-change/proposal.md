# Smoke change

## Why
The smoke change exercises the orchestrator flow end to end on a tiny Go module. It covers parallel waves, review of a task submitted before the session with a missing scenario, a reviewer rejection and resume after a reset.

## What Changes
- Greeting trims names and greets the world for an empty name.
- Sum handles an empty slice and a new Max function returns the largest element.
- Clamp bounds a value and rejects an inverted range.
